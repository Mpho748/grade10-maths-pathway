# Grade 10 Maths Pathway

An iPad-friendly diagnostic and targeted-support pilot aligned to the SACAI Grade 10 Mathematics ATP.

## Use

Open `index.html` in a browser, or upload the folder to GitHub Pages. No installation is required.

## Included

- Learner profile creation
- 22-question diagnostic across all Grade 10 ATP topics
- Automatic topic mastery bands and personalised pathway
- Worked examples and targeted practice
- Facilitator dashboard with learner priorities and attempts
- Apple Pencil or finger working canvas on diagnostic and support questions
- Saved handwritten working attached to learner evidence
- AI-assisted handwriting reading through a protected Supabase Edge Function
- Immediate feedback on the learner's written method
- Learners must rewrite working that the AI cannot read or considers insufficient
- Possible error categories such as signs, arithmetic, formula choice and substitution
- JSON export for backup or sharing
- Password gate for facilitator-only dashboard access
- Shared Supabase database for progress from all learner devices
- Secure facilitator email-and-password authentication
- Local fallback when a learner temporarily loses internet access
- Compulsory Apple Pencil/finger working before answer choices unlock
- Adaptive follow-up probes after the first error in a topic
- Likely misconception labels (for example signs, substitution, formulas or arithmetic)
- Facilitator review of each handwritten response alongside the selected answer
- Balanced practice sessions combining targeted support with spaced review of secure topics

## Pilot limitation

Learner records are sent to the shared Supabase database and also retained locally as a fallback. AI handwriting interpretation can make mistakes, so the facilitator should review the saved handwritten evidence before making an intervention decision.

## Important

This tool supports learning and identifies likely gaps. Its scores should not be used as formal assessment marks without teacher review.
